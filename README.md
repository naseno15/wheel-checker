# พิกัดล้อ · Wheel Checker

Offline multi-fleet locomotive wheel measurement field app (Qt 6 / QML / C++20).

Classes: Alstom ALS, GEK, Hitachi, GEA, CSR, QSY.

## Repo

https://github.com/naseno15/wheel-checker

## Build

```powershell
powershell -NoProfile -File .\fast.ps1
powershell -NoProfile -File .\fast_static.ps1
```

Outputs: `build\wheel_limits_cpp.exe`, `build-static\wheel_limits_cpp.exe`
